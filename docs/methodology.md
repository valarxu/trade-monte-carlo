# 方法与复现

## 样本和顺序

分析单位为一条已平仓交易。先按账户和交易对筛选，再按平仓时间升序排序；同一时间保留输入顺序。没有时间列时保留文件顺序。`BTC-USDT` 与 `BTC-USD` 等不同交易对不会自动合并。账户名、记录 ID、金额字段和原文件路径不进入分析报告的数据集合。

## 收益区间

| 区间 | 精确边界（r 为百分数） |
|---|---|
| ≤−10% | r ≤ −10 |
| −10～−5% | −10 < r ≤ −5 |
| −5～−3% | −5 < r ≤ −3 |
| −3～−1% | −3 < r ≤ −1 |
| −1～0% | −1 < r < 0 |
| 0% | r = 0 |
| 0～1% | 0 < r < 1 |
| 1～3% | 1 ≤ r < 3 |
| 3～5% | 3 ≤ r < 5 |
| 5～10% | 5 ≤ r < 10 |
| ≥10% | r ≥ 10 |

第 i 个区间历史计数为 nᵢ、总笔数为 N、计数容差为 t。每条模拟取整数计数 cᵢ：

```text
ceil(nᵢ × (1 − t)) ≤ cᵢ ≤ floor(nᵢ × (1 + t))
Σ cᵢ = N
历史胜率 − w ≤ Σ(正收益区间 cᵢ) / N ≤ 历史胜率 + w
```

历史计数为零的区间保持零。零收益不算盈利。小区间受整数限制可能冻结。例如默认 t=20% 时，原始10笔可为8–12笔，原始3笔只能保持3笔。

## 条件多项分布

按历史区间概率 pᵢ=nᵢ/N，在满足上述限制的所有计数组合中，选择概率与以下值成正比：

```text
∏ (pᵢ ^ cᵢ / cᵢ!)
```

固定 N 后多项式的 N! 对所有组合相同，可省略。项目将正收益与非正收益区间分组，分别计算有界计数多项式的后缀卷积，再条件抽取总盈利笔数与各区间计数。每阶段做与计数无关的常数归一化以控制浮点范围。它与枚举所有合法向量后按同样权重抽样等价，但无需保存指数数量的组合。

测试包含一个可完全枚举的小样本，对照每个盈利笔数的精确概率，以及完整计数向量的抽样频率。零容差、全零、全盈利和全亏损样本另有测试。

随后在每个区间内从历史收益率中有放回抽取恰好 cᵢ 笔，再使用 Fisher–Yates 打乱顺序。不在区间内凭空均匀生成收益，也不固定盈亏比。随机种子控制整个过程；相同数据、参数与项目版本可复现。

## 资金、回撤与触线

```text
equity₀ = 1
 equityₜ = equityₜ₋₁ × (1 + return_pctₜ / 100)
最终收益率 = (equityₙ − 1) × 100%
最大回撤 = maxₜ(1 − equityₜ / maxₛ≤ₜ(equityₛ)) × 100%
```

触线按 `equityₜ < riskFloor × equity₀` 判断。默认 riskFloor=0.5，严格低于才计入。只要曾发生就保留标记，即便最终恢复。期末低于阈值单独统计。路径继续计算，触线比例不等同实际交易所强平概率。

只观察逐笔完成后的净值，不观察持仓中的价格路径和浮亏。同样的交易价格收益率不能完整重建真实账户权益。

## 统计

收益率、回撤均值和概率使用全部模拟，图上仅抽取约150条，并额外保留终值和风险极端样本。曲线展示抽样不影响统计分母。

连续变量百分位使用线性插值；最长连亏的 P95 用向上取秩，保留整数笔数。收益标准差使用本批模拟的总体标准差。最差5%均值取最终收益最低的 `ceil(0.05 × 模拟数)` 条。盈亏比是单条路径平均正收益率与平均负收益率绝对值之比，再跨路径取中位数；无盈利或无亏损时为不可用。

不同币种各自缩放纵轴，不做组合资本分配。没有计算年化收益或夏普比率。

## 局限

这是一种受约束的历史重采样。它限制胜率与分布偏离、保留样本已有尾部，不表示未来会继续服从该分布。没有模拟交易费用、滑点、市场冲击、相关性、连亏的市场依赖或新制度。极值不是未来边界，模拟中的低触线率不能当作真实风险保证。
